# lib/remotion: the shared film toolkit (PLAYBOOK §8, §10)

Import from a film with a relative path (`../../../../lib/remotion`). The film's `remotion.config.ts` resolves this
folder's imports from the film's own `node_modules` (see `films/tata-history/remotion/remotion.config.ts`), and its
`tsconfig.json` includes this folder.

| File | What |
|---|---|
| `brand.ts` | Colours and font names, generated by `scripts/brand_ts.py` from `config/brand.yaml` (never edit by hand) |
| `fonts.ts` | `loadBrandFonts()` (vendored Cinzel, Inter latin + latin-ext for ₹, JetBrains Mono) and `fontStacks` |
| `motion.ts` | `ease` curves, `tween()` (clamped, eased), `envelope()`, `pop()` (spring from a frame) |
| `timing.ts` | `makeTiming(json)`: `sentence(text)`, `word(sentence, phrase)`, `wordEnd()`, `chapter(title)` → frames |
| `Camera.tsx` | `Camera` (keyframed push/pan/tilt + seeded handheld drift), `Push` |
| `Atmosphere.tsx` | `Grain`, `Vignette`, `LightLeak`, `Dust`, `Embers`, `Letterbox`, `Atmosphere` (the standard stack) |
| `Photo.tsx` | `grades` per era, `FullPhoto` (cover/contain on a blurred fill), `Footage`, `Print` (photo on the desk), `Desk`, `Fade` |
| `Type.tsx` | `Stamp` (place/date), `LowerThird`, `Counter` (Indian grouping, lands on a frame), `Kinetic`, `inr()` |
| `Document.tsx` | `Paper` (isometric document), `Highlight` (sweeps as the voice reads), `PaperText` |
| `Brand.tsx` | `LogoBug`, `HonestyTag` (RECONSTRUCTION / ILLUSTRATION / ARCHIVE …) |
| `three/Diamond.tsx` | A code-built cut gem (mirror facets in a jewellery-studio environment). Not yet film quality: real diamond footage first |
| `ink/` | INK figures (PLAYBOOK §8.9). `reference_stick.js` is Creator's rig to port |

Rules (PLAYBOOK §10.2): every value is a function of the frame; `random(seed)` and `@remotion/noise` only; eased or
spring motion only; frames come from the VO timing, never typed by hand.

## Measured in the cloud container (2026-10-25)
- **WebGL:** `npx remotion still … --gl=swangle` works for `@remotion/three` (software GL). `--gl=angle` failed here.
- **Environment maps** must be built in the canvas's `onCreated` (before the first frame). A `useEffect` runs after a
  still is captured and the scene renders black.
- **Glass transmission** (`MeshPhysicalMaterial.transmission`) renders as a flat milky blob under software GL. Fake
  gems and glass with mirror facets and a designed environment.
- **Composition props are serialised:** never pass a component through `defaultProps`; wrap it in a closure
  component (`chapterComp(title, Body)` in the film's `Chapter.tsx`).
